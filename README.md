One sentence (at most 200 characters) explaining the modern internet to
a time traveler who has just stepped out of the year 1800 — built only
from things a person from 1800 could picture: a road, a post office,
a library, a letter, a book.

## The sentence

> Picture every post office and library on earth joined by one road, so any letter, book, or spoken word can reach any door before you finish a breath, and an answer can come back just as fast.

191 characters, one sentence.

## How to run

```sh
python3 main.py
```

Writes the sentence to `/output/entry.txt` (Python stdlib only,
deterministic — the same bytes on every run).
